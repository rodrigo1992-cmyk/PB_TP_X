    TIPO: String
    OBJETIVO DE USO: Título normalizado fornecido pelo site, pode facilitar a análise.

    TIPO: String
    OBJETIVO DE USO: Precisa ser tratado para virar valores numéricos. Servirá para comparar sênioridade x salário ou requisitos x salário

    TIPO: String
    OBJETIVO DE USO: filtros no dashboard

CAMPO: estado
    TIPO: String
    OBJETIVO DE USO: filtros no dashboard

CAMPO: cidade
    TIPO: String
    OBJETIVO DE USO: filtros no dashboard

CAMPO: url
    TIPO: String
    OBJETIVO DE USO: URL Necessário apra acessar o detalhamento da Vaga

CAMPO: descricao
    TIPO: String
    OBJETIVO DE USO: Necessário para que o modelo de LLM consiga obter as funções e requisitos
