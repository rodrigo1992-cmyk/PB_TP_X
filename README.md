## Instruções para Execução do Aplicativo:
- Para visualizar no Streamlit, executar arquivo "*app\pages\app_streamlit.py*"
- Para subir o servidor com uvicorn, acessar a pasta "*app\router*" e executar o comando "*uvicorn paths:router --reload*"
